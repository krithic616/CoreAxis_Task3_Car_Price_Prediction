# Dataset

The Task 3 analysis uses the used-car dataset specified by CoreAxis Technology.

**Source:** Kaggle — `vijayaadithyanvg/car-price-predictionused-cars`

The original dataset contains 301 observations and 9 columns. The analysis found 2 exact duplicate rows and no missing values; 299 observations were used for modeling after duplicate removal.

The original CSV is retained in the local submission package. It is not duplicated in this GitHub repository because the repository version must not contain an incomplete dataset copy.
