# Task 3 Visualizations

The final local submission package contains the generated visualization files for:

- Selling price distribution
- Selling price vs present price
- Selling price vs car age
- Selling price by fuel type
- Correlation matrix
- Gradient Boosting actual vs predicted values
- Gradient Boosting feature importance

The plotting code is included in `src/car_price_prediction.py`. The generated charts are also included in the downloadable Task 3 submission ZIP.
